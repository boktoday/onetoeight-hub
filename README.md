## Source

This repo mirrors content hosted on the here.now drive (`drv_01kq8g6hkfmnmfqngr18xyx3mb`). The here.now version remains the live production deployment. GitHub here is the version-controlled, stable-URL mirror.

## Deploy

This repo is ready for **GitHub Pages** deployment. To enable:
1. Repo Settings → Pages
2. Source: Deploy from a branch → `main`
3. Folder: `/` (root)
4. Save

The site will be live at `https://boktoday.github.io/onetoeight-hub/`.

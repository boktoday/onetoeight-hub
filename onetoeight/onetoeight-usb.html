Questions

Things people ask.

Do I need an internet connection? +

No. The USB runs 100% airgapped. Once booted, it doesn't need Wi-Fi, Ethernet, or any network connection at all. Everything — image generation, LLM chat, transcription, TTS — runs locally from the drive.

What computers does it work on? +

Almost any computer running Windows, macOS, or Linux. You boot from the USB drive — it doesn't install anything on the host machine. When you're done, your outputs are saved back to the drive and the host is untouched.

Do I need a powerful computer? +

No. The software is designed to be ultra-lightweight. It runs smoothly on modest hardware without needing a high-end enterprise rig. If your computer was made in the last 5-7 years, it will likely work well.

Are my prompts and data really private? +

Yes. Because the system runs completely airgapped, your prompts, data, and generated assets never touch a third-party server. There are no API calls, no telemetry, no cloud processing. It's local-first, privacy-first AI.

Is the AI uncensored? +

The LLMs included are uncensored local models. You get full control over your prompts without filters, guardrails, or content policies imposed by cloud providers. You are responsible for how you use this freedom.

What's included in the kit? +

The complete kit includes: the bootable USB drive with the full AI studio, a printed 140-page guidebook, and additional extras. Everything you need to start creating privately, right out of the box.

Is this only for faith-based groups? +

No. The guidebook is designed for any context — churches, schools, community centres, and informal groups. Essentials 1–7 are universal. Essential 8 (Tested Convictions) is written to work for any worldview, with an appendix showing how to customise it for your faith tradition if you wish.
